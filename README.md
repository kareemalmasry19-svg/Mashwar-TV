# مشوار TV — النسخة 0.1 (أندرويد)

مشغّل قوائم M3U / IPTV بواجهة عربي ووضع عربية (شاشة بالعرض وزراير كبيرة).
التطبيق مشغّل بس، مفيهوش أي قنوات جاهزة. انت بتضيف القائمة بتاعتك.

## المميزات في النسخة دي
- إضافة قائمة من رابط M3U، أو من ملف على الموبايل، أو قائمة تجريبية للتجربة.
- قراءة `tvg-logo` و`group-title` و`#EXTGRP`، وخيارات VLC للـ User-Agent والـ Referer، وصيغة `url|User-Agent=...`.
- تقسيم حسب المجموعات، وبحث، ومفضلة، وزرار "كمّل آخر قناة".
- مشغّل ExoPlayer (Media3) بيشغّل HLS وDASH وMP4 وTS، وبيتعامل تلقائي مع البث المباشر لما يتأخر.
- شاشة كاملة بالعرض، وزراير كبيرة (السابقة / تشغيل / التالية)، والزراير بتختفي لوحدها بعد 4 ثواني.
- ثلاث أوضاع للصورة: ملائم / تكبير / مطّ.
- تحديث القائمة أو مسحها، وكل البيانات بتفضل على الموبايل بس.

## طريقة البناء
### الطريقة الأولى: Android Studio
1. افتح فولدر `MashwarTV` من Android Studio.
2. استنى لحد ما Gradle يخلّص (Sync).
3. وصّل الموبايل وشغّل **Run**، أو من القائمة: Build ▸ Build APK(s).

### الطريقة التانية: GitHub من غير ما تنزّل حاجة
1. ارفع الفولدر على Repository جديد على GitHub.
2. هتلاقي الـ workflow الجاهز (`.github/workflows/build-apk.yml`) شغّال لوحده.
3. من تبويب **Actions** ▸ آخر Build ▸ نزّل `MashwarTV-apk`.

## التثبيت على الموبايل
افتح ملف `app-debug.apk`، ووافق على "التثبيت من مصادر غير معروفة".
