# المصري TV — نسخة شاشات سامسونج (Tizen)

تطبيق ويب لشاشات سامسونج (Tizen 4.0 وأحدث، يعني موديلات 2018 وبعدها):
- فولدرات: القنوات المجانية، وحسابات Xtream، وروابط M3U
- Xtream: بث مباشر وأفلام ومسلسلات بنفس ترتيب السيرفر
- مشغّل AVPlay بتاع سامسونج، وقائمة قنوات زي الريسيفر (◀)، وتقليب بالأرقام وزراير CH
- الفيلم يكمّل من مكان ما وقفت، والحلقة الجاية تشتغل لوحدها

التسطيب: شوف خطوات "تسطيب المصري TV على شاشة سامسونج".

الاختبار: `python3 tools/tv_test.py` بيشغّل التطبيق في Chrome على 1920×1080 وبيحرّكه بزراير الريموت مع سيرفر Xtream وهمي.
